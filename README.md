# Rosé Pine Dawn for MikuTV

All natural pine, faux fur and a bit of soho vibes — sunlit dawn rose palette for MikuTV.

- **Plugin ID**: `rose-pine-dawn`
- **Kind**: `theme` (`light` appearance, daytime pair for **Rosé Pine**)
- **Version**: `1.0.0`
- **License**: Apache-2.0

## Installation

1. Open **MikuTV** on Apple TV.
2. Go to **设置 → 外观与动态 → 白天主题 → 发现更多主题** (or **设置 → 插件管理 → 发现插件**).
3. Select **Rosé Pine Dawn** (`yuchanns/mikutv-theme-rose-pine-dawn`) and install.
